# Smart School Management System

A full-stack school management platform built using React and Spring Boot that enables administrators, teachers, and students to manage academic activities, users, assignments, and school operations securely.

## Demo

Live Application: https://smart-school-frontend-rk3s.onrender.com/
Deployed using:
- Frontend: Render
- Backend: Render/AWS EC2
- Database: MongoDB Atlas
- Reverse Proxy: Nginx
## Features
### Authentication & Authorization
- JWT based authentication
- Role based access control
- Protected routes
- Secure API endpoints

### Admin Module
- Manage students
- Manage teachers
- User activation/deactivation
- View analytics dashboard

### Teacher Module
- Create assignments
- Manage classes
- Track student activities

### Student Module
- View assignments
- Submit academic activities

### Analytics
- Dashboard statistics
- Performance tracking
- Data visualization
## Tech Stack:
